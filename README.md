# Syntecxhub Data Science Internship - Week 2 Task

## Project 1: Time Series & Category Charts

### Project Overview
This repository contains the completed project for **Project 1: Time Series & Category Charts** under Week 2 of the Syntecxhub Data Science Internship program.

---

## Tasks Completed
1. **Time Series Analysis:** Aggregated daily sales into monthly intervals and plotted trends using line charts.
2. **Category Comparison:** Compared revenue performance across categories using bar charts and analyzed proportional market share using pie charts.
3. **Visualization Exports:** Saved all generated charts to high-resolution PNG format (`monthly_sales_trend.png`, `category_sales_bar.png`, `category_share_pie.png`).
4. **Formatting & Documentation:** Included complete label, legend, and axis adjustments with chart rationale.

---

## Chart Selection Rationale & Formatting

### 1. Line Chart (`monthly_sales_trend.png`)
* **Rationale:** Best suited for time series data to highlight continuous sales growth and seasonal fluctuations across months.
* **Formatting:** Rotated x-axis month labels (45°), added data markers, and labeled axes clearly.

### 2. Bar Chart (`category_sales_bar.png`)
* **Rationale:** Clearly compares sales figures across distinct, non-continuous product categories.
* **Formatting:** Sorted categories in descending order with color gradients for enhanced visual impact.

### 3. Pie Chart (`category_share_pie.png`)
* **Rationale:** Effectively presents categorical share relative to total sales volume.
* **Formatting:** Displays exact percentage annotations (`autopct`) with clear pastel category legends.
